# Skills Starter Kit — Stock Analysis Pipeline

Generic agentic engineering skills and mandatory rules files.
Drop `skills/` into `~/.hermes/skills/software-development/` and `rules/` into any project root.

## Skills included (non-Codex-specific)
- **think-in-code** — Replace N sequential reads with 1 execute_code pass
- **karpathy-coding-principles** — 4 principles for AI-generated code
- **systematic-debugging** — Hypothesis-driven debugging methodology
- **completion-verification-checklist** — 5-phase self-review before declaring done
- **agentic-engineering-review** — Post-Codex code quality review
- **scope-discipline** — Prevents working on adjacent projects
- **stuck-delegate-learn** — 3-strikes rule, delegate don't loop
- **env-loading-pattern** — Correct .env loading (no setdefault)
- **background-thread-distrust** — Render/Serverless thread safety

## Rules files
- **AGENTS.md** — Compact security/sandbox/git/validation rules (~700 tokens)
- **SKILLS_TEMPLATE.md** — Template for project-specific SKILLS.md
- **KARPATHY.md** — 4 coding principles (Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven)
