### P2 — 2 (non-blocking, carried from T5 review)

1. **simplifyLabel() order fragility** — checks "premium"/"discount" before "above/below peer median". Works correctly for current label set but could produce wrong output if new labels are added.
2. **No React error boundary** — a render-time crash in PeerBenchmarkGroup would unmount the entire AnalysisCard tree. Mitigation: the component already handles loading/error/unavailable states gracefully.

### P3 — 1 (observation, not a bug)

3. **Quality metrics limited to 1/1** — API returns only `total_debt` in the quality category for live NVDA/AAPL/TSLA. The other 8 quality metrics (gross_margin, roic, roe, etc.) are unavailable from yfinance for peers. This is a data source limitation, not a code defect. The engine correctly shows "No data available" when no quality metrics are available for rendering.
