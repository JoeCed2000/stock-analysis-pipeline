# Earnings Call Deep-Dive — Specification
# Source: Ced's spec document (Earnings Documents.pdf)
# Extracted: 2026-05-05

## Overview
Comprehensive earnings call analysis template producing structured bilingual (EN/JP) investor reports.

## Required Sections

### 1. EPS & Revenue Summary
- Table: Estimate vs Actual vs Estimate Variance vs YoY Change
- Example (GEV Q1 2026): EPS $1.79-$1.95 est → $17.44 actual (+$15 vs est, +16% YoY from $8.03B base)
- Revenue: $9.27B-$9.29B est → $9.34B actual (+$0.5B-$0.7B vs est, +1500% from $0.91B base)

### 2. Highlights & Lowlights
- 🌟 Highlights (good points) — numbered, with evidence
- ⚠️ Lowlights (concerns) — numbered, with severity
- Japanese format with detailed bullet analysis

### 3. Operating Metrics
- Table + Analysis: Revenue, Gross Profit/Margin, OpEx, Operating Income/Margin, Net Income
- YoY comparison for all metrics
- Example (AAPL Q2 2026): Revenue $111.18B (+16.6%), Gross Margin 49.3% (+2.3pt), OpEx $18.90B (+23.7%), Op Income $35.89B (+21.3%), Op Margin 32.3% (+1.3pt), Net Income $29.58B (+19.4%)

### 4. Cash Flow
- Table: OCF, CapEx, FCF with YoY
- Analysis of cash generation quality
- Example (AAPL): OCF $82.63B (+53%), CapEx $4.34B (-28%), FCF $78.28B (+63%)

### 5. Capital Efficiency
- ROE, ROTCE/ROTE, ROA, ROIC
- Interpretation of what drives the numbers
- Example (AAPL): ROE ~65-70%, ROTCE ~80%, ROA ~16-18%, ROIC ~45-55%

### 6. Segments
- By product category (table)
- By geography (table)
- Analysis of mix shifts, concentration risks

### 7. Forward P/E
- Current forward P/E and context

### 8. Backlog Quality (conditional — certain companies only)
- Quantity: how much (dollar amount, quarters of coverage)
- Quality: firm commitments vs soft pipeline
- Example (SanDisk): NBM contracts $42B minimum guaranteed, ~7 quarters coverage, financial guarantees $11B+

### 9. Guidance
- Next quarter guidance table
- QoQ analysis
- Medium-term directional signals
- Example (SanDisk Q4 guide): Revenue $7.75B-$8.25B, Gross Margin 79-81%, EPS $30-$33

### 10. Verdict / 総合評価
- Structured analyst verdict
- One-line summary (一言まとめ)

## Format Rules
- Each section: question in EN + JP, then structured answer
- Tables for all numerical data
- 🌟⚠️🧠🎯🧩💰 emojis for visual markers
- "Nami-san向け" (for Nami) annotations — Japanese investor perspective
- Every section ends with 一言まとめ (one-line summary)

## Language
- Bilingual EN+JP by default in the spec examples
- User configures output language
